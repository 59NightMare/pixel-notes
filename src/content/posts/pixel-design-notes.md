我第一次认真研究像素界面，不是为了复刻某台旧掌机，而是因为现代界面开始让我感到疲惫：边界越来越模糊，装饰越来越柔软，真正重要的操作反而藏了起来。

> 限制本身不会带来风格。只有当限制帮助我们做出一致的决定时，它才会成为设计语言。

## 从整数网格开始

像素设计最有价值的部分，是它强迫我们处理清楚位置与比例。图标不该停在半个像素上，边框不该在不同区域忽粗忽细，间距也不应该凭感觉漂移。

这个博客使用 4px 作为基础单位。正文的细节仍可以使用 1px 或 2px，但组件之间的主要距离都回到 4 的倍数。

## 有限色板不是少用颜色

纸白和墨黑承担阅读，绿色表达在线与积极状态，珊瑚红负责主要动作，黄色用于短暂强调，蓝色和紫色只服务于内容插画。

```css
:root {
  --paper: #fffaf0;
  --ink: #171923;
  --signal: #5ee18f;
  --action: #ff6b6b;
}
```

## 反馈应该像按键一样明确

Pixelium 的像素边框不仅是装饰，它也描述了按钮与表面的关系。按下状态通过边框、颜色和位移明确表达，不需要额外动画。

## 所有内容使用同一像素字体

这个博客最终选择让标题、摘要、正文、目录和代码全部使用 Fusion Pixel。统一的字体使像素语言更加彻底，字号与行距则负责维持阅读节奏。

## 最后：给内容留出安静

像素装饰集中在封面和界面边缘，正文区域只保留清晰的标题、段落和代码。读者进入文章之后，品牌感应该逐渐退后，让观点站到前面。
